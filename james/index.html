Student Visual Hierarchy Documentation

Document the specific CSS strategies you implemented for at least 5 elements to establish visual hierarchy.

Target Element / Class Hierarchy Principles Applied Implementation Details & Design Rationale
.hero-title (h1) Size & Scale, Color & Contrast, Reading Patterns Made this the largest text on the page (2.75rem, bold) with high-contrast text color so it acts as the primary Level 1 focal point in a Z-pattern layout flow.
#site-header Alignment, Spacing, Reading Pattern The header uses a horizontal layout that guides the user's eyes from the top-left toward the top-right. This establishes the first horizontal line of the Z-pattern.
.nav-cta Color & Contrast, Emphasis I use a strong background color and contrasting text to the Enroll Now button to attract attention at the end of the top horizontal.
.hero-description Spacing, Alignment, Reading Pattern The description is positioned below the hero title and aligned to the left. This supports the diagonal movement of the user's eyes toward the lower part of the section.
.hero-actions Alignment, Proximity, Emphasis The action buttons are grouped together below the hero content. The placement of this two creates a clear endpoint for the diagonal movement and directs users toward the next section.
.section-title Size & Scale, Emphasis, Spacing I make the section title larger and separated from the surrounding content, because This position provides a strong visual starting point for the lower horizontal part of the Z-pattern.
